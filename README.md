The world in one day: a newspaper front page summing up Monday 23 November 2026. Six stories lead the page — the COP31 climate summit in Antalya ending with no deal, the AI stock sell-off rattling world markets (Nikkei -5.1%, S&P -3.7%), the Russian strike on Dymer in the Kyiv region killing 11, the factory fire in Cikande, Indonesia killing 24, Trump threatening to sink Iranian ships after a US strike on an oil tanker, and the capture of FBI most-wanted cartel leader "Chapo Isidro" in Sinaloa — with sport (Marc Marquez's eighth MotoGP title, Liverpool 4-0 Manchester United) and the day in brief in the footer. The image is drawn entirely in code by `main.py` (Python 3.13, standard library only): a 5x7 bitmap face, geometric pictograms, and a hand-written PNG encoder. No photographs, no fonts on disk, no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Two runs produce byte-identical `entry.png` (1024x1024, ~22 KB).
